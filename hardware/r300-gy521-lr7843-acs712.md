# R300 wiring baseline: GY-521, LR7843 and ACS712-05B

This file supersedes only the ADXL345, L9110 and INA180 portions of the v4
pin map. UART, AVR safety relay, E-stop and power-domain wiring remain as in
the generated link contract. Do not apply motor power until the checks below
have been completed with a multimeter and a current-limited supply.

## Fixed STM32 wiring

| STM32F411 | Module pin | Connection |
|---|---|---|
| 3V3 | GY-521 VCC | Power from 3.3 V so I2C pull-ups cannot drive 5 V into STM32 |
| GND | GY-521 GND | Common signal ground |
| PB10 / I2C2_SCL | GY-521 SCL | 400 kHz I2C, AF4 open-drain |
| PB3 / D3 / I2C2_SDA | GY-521 SDA | 400 kHz I2C, AF9 open-drain; NUCLEO-F411RE CN10-31 |
| PB1 / EXTI1 | GY-521 INT | Data-ready, rising edge |
| GND | GY-521 AD0 | Select address `0x68` |
| PA0 / ADC1_IN0 | ACS712 OUT | Through 12 kohm; add 22 kohm PA0-to-GND and 100 nF PA0-to-GND |
| PB6 / TIM4_CH1 | LR7843 module PWM/IN | 1 kHz active-high PWM, 3.3 V input |
| PB7 | Not connected | Firmware holds it low |

## Motor-current path

Use this series path:

`current-limited motor supply + -> AVR safety relay NO -> ACS712 IP+ -> ACS712 IP- -> R300 motor + -> R300 motor - -> LR7843 drain/output -> LR7843 source/GND -> supply -`

Place a flyback diode directly across the motor: cathode to motor `+`, anode
to the LR7843 drain/motor `-`. Fit a 100 kohm gate/input pulldown if the module
does not already have one. STM32, ACS712, LR7843 input and motor-supply grounds
must share a star ground; power the Jetson from its own supply and join only
the signal ground.

The ACS712 itself is powered from 5 V. Its nominal 2.5 V zero-current output
becomes about 1.62 V at PA0 through the 12k/22k divider; a possible 5 V output
becomes about 3.24 V, below the 3.3 V ADC rail. Firmware averages 256 samples
while the motor is off, so module offset is calibrated at every boot.

## R300_HW_TUNE checks before energizing

1. The selected current module is `ACS712-05B`, 5 A and 185 mV/A. Keep
   `R300_ACS712_SENSITIVITY_MV_PER_A=185` unless the physical module is replaced.
2. The selected LR7843 module accepts 3.3 V active-high input. Keep
   `R300_LR7843_PWM_ACTIVE_HIGH=1`. This does not permit substituting a bare
   IRLR7843 directly on PB6.
3. With the relay open and motor disconnected, confirm GY-521 SCL/SDA never
   exceed 3.3 V and PA0 remains within 0..3.3 V.
4. Start at 0% duty with a current-limited supply, verify the flyback diode
   polarity, then increase duty gradually while watching MOSFET, motor and
   connector temperature.

The software intentionally permits forward rotation only. Reversing an R300
motor requires swapping its leads while power is isolated; dynamic reverse or
braking requires an H-bridge and is outside this LR7843 design.
