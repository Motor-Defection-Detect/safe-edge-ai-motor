2. 모터 전력 경로와 LR7843

반드시 무전원 상태에서 배선한다. K1은 접점의 정격 전압·연속 전류·돌입 전류가 R300 모터의 실측 stall 전류를 감당하는지 확인해야 한다.

배선 순서

  1. 모터 전원 +를 K1 COM에 연결하고, K1 NO를 ACS712 IP+에 연결한다.
  2. ACS712 IP− → R300 모터 + → 모터 − → LR7843 Drain/OUT 순으로 연결한다.
  3. LR7843 Source/GND를 모터 전원 −에 연결한다.
  4. flyback diode를 모터 양단에 최대한 가깝게 단다. 캐소드(띠)=모터+, 애노드=모터−/Drain.
  5. STM32 PB6 → 모듈 PWM/IN, STM32 GND → 모듈 신호 GND. 모듈에 input pull-down이 없다면 100 kΩ을 IN-GND에 추가한다.
동작
PB6 HIGH 동안 LR7843가 켜져 모터 전류가 흐른다. 펌웨어는 1 kHz PWM, 부팅 0%, 정방향만 허용한다.
제한
LR7843는 low-side 스위치다. 역회전·능동 제동은 불가능하며 필요하면 전원 차단 후 모터선을 교체하거나 H-bridge로 재설계한다.

3. GY-521과 ACS712 아날로그 입력

GY-521 / MPU-6050

  • VCC → STM32 3V3, GND → 공통 GND
  • SCL → PB10, SDA → PB11, INT → PB1
  • AD0 → GND, 주소 0x68
  • I²C 400 kHz, 가속도 ±16 g, data-ready 1 kHz
  • 모듈 pull-up이 5 V에 연결되지 않았는지 전압 측정

ACS712-05B

  • VCC → 5 V, GND → 공통 GND
  • IP+/IP−는 모터 전류 경로에 직렬
  • OUT은 12 kΩ을 거쳐 PA0로 입력
  • PA0에 22 kΩ과 100 nF를 각각 GND로 연결
  • 부팅 시 모터 OFF 상태 256 샘플 영점 보정

ACS712 출력 보호 회로

분압비 = 22 / (12 + 22) = 0.6471
영점: 2.5 V × 0.6471 ≈ 1.62 V
최대: 5.0 V × 0.6471 ≈ 3.24 V < STM32 ADC 3.3 V
전류: mA = (ADCraw − ADCzero) × 3300 × 34 × 1000 / (4095 × 22 × 185)
오차 원인: 저항 공차, 5 V 전원 오차, 센서 온도·영점 편차가 남는다. 185 mV/A는 기본값이며 실제 전류계와 비교해 보정값을 기록한다. ACS712-05B의 ±5 A 범위를 넘기지 않는다.

4. 전원·접지 규칙과 최초 기동

전원 및 접지

  • GY-521은 3.3 V, ACS712는 5 V, Jetson은 제조사 권장 별도 PSU를 사용한다.
  • STM32·ATmega128A·ACS712 신호 GND·LR7843 입력 GND·모터 전원 −는 한 점의 스타 접지로 모은다.
  • 모터 고전류선은 센서 I²C/ADC/UART 선과 떨어뜨리고, 전류 루프를 짧고 굵게 배선한다.
  • Jetson에는 모터 전원을 공급하지 않는다. Jetson과 제어부 사이에는 UART 신호와 신호 GND만 연결한다.
  • K1 접점, ACS712 단자, 커넥터, 배선 굵기, flyback diode는 R300의 실측 stall 전류를 기준으로 선정한다.

최초 기동 체크리스트

  1. 모터 전원과 USB/J-Link 전원을 모두 분리하고 단락·극성·연속성을 검사했다.
  2. K1이 무전원/리셋 상태에서 열려 있고, PD7의 실제 active-high 극성을 확인했다.
  3. flyback diode 방향이 캐소드=모터+, 애노드=모터−/Drain임을 확인했다.
  4. GY-521을 3.3 V로 켠 뒤 SCL/SDA가 3.3 V를 넘지 않으며 WHO_AM_I=0x68임을 확인했다.
  5. ACS712를 5 V로 켜고 모터 OFF 상태에서 OUT≈2.5 V, PA0≈1.62 V, PA0<3.3 V를 측정했다.
  6. PB6이 리셋/부팅 중 LOW이고, PWM 0%에서 LR7843 출력이 OFF인지 측정했다.
  7. PB8 heartbeat가 Jetson/센서 비정상 시 멈추고 500 ms 이후 릴레이가 차단되는지 확인했다.
  8. 전류 제한값을 낮게 설정하고 PWM을 0%에서 조금씩 올리며 전류·회전 방향을 확인했다.
  9. MOSFET, 모터, 릴레이, 커넥터, 배선 온도를 기록하고 안전 한계 이내인지 확인했다.
  10. E-stop을 눌렀을 때 PWM과 K1이 차단되고 자동 재기동하지 않음을 확인했다.

금지 배선

  • 5 V를 STM32 PA0, PA2/PA3, PA10, PB1, PB6, PB10/PB11에 직접 넣지 않는다.
  • ATmega PE1(5 V TX)을 STM32 PA10에 레벨 변환 없이 직접 연결하지 않는다.
  • bare IRLR7843 게이트를 PB6에 직접 대체 연결하지 않는다. 확정된 3.3 V active-high 입력 모듈만 사용한다.
  • flyback diode 없이 모터를 스위칭하거나 diode 방향을 반대로 연결하지 않는다.
  • ACS712 OUT을 분압 없이 PA0에 연결하지 않는다. IP+/IP−를 전원/GND 센스 입력처럼 병렬 연결하지 않는다.
  • K1을 우회하거나 AI/Jetson 출력으로 릴레이를 직접 구동하지 않는다.
  • 모터 회전 중 배선을 바꾸거나, PB7을 역회전 신호로 사용하지 않는다.
